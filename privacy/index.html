Privacy

Last updated 8 October 2026. ARQCA does not run a cloud IDE and does not ask this website for your source code or AI keys.

This website

arqca.me is a static marketing site. There are no accounts, no forms that collect API keys, and no upload of your projects. The Windows installer is hosted on a public GitHub Release; clicking Download sends you there.

The desktop app

ARQCA (the Nexus desktop IDE) runs on your computer. Workspace files stay on disk. AI API keys you paste in Settings are stored in Windows Credential Manager on that machine. They are not sent to arqca.me.

Updates

Installed copies check a public file at /updates/latest.json to see if a newer installer exists. That file does not identify you.

Hosting

GitHub Pages and GitHub Releases may log standard request metadata (such as IP address) under GitHub's own policies. We do not operate a separate analytics product on this site.
